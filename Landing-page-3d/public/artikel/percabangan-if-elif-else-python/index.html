Percabangan If, Elif, Else di Python dengan Contoh

Program menjadi pintar ketika bisa memilih: memberi diskon bila belanja cukup banyak, menampilkan pesan berbeda untuk nilai yang berbeda, atau menolak kata sandi yang terlalu pendek. Semua itu memakai percabangan. Di Python, percabangan ditulis dengan if, elif, dan else.

Oleh Muhammad Muchson Attoyibi·28 Oktober 2026·1 menit baca

Bentuk dasar

nilai = 82

if nilai >= 85:
    print("A")
elif nilai >= 70:
    print("B")
elif nilai >= 55:
    print("C")
else:
    print("Perlu remedial")

Python memeriksa kondisi dari atas ke bawah dan menjalankan blok pertama yang benar, lalu melewati sisanya. Karena itu urutan kondisi penting: periksa batas tertinggi dulu.

Urutan menentukan hasil

Bila urutannya dibalik (cek >= 55 dulu), nilai 82 akan masuk "C" karena kondisi pertama yang benar langsung dipakai. Ini kesalahan klasik.

Kondisi bersarang

punya_tiket = True
umur = 15

if punya_tiket:
    if umur >= 13:
        print("Silakan masuk")
    else:
        print("Harus didampingi orang dewasa")
else:
    print("Beli tiket dulu")

Kondisi bersarang boleh, tetapi bila lebih dari dua tingkat, kode sulit dibaca. Pertimbangkan menggabungkan dengan and atau memakai "keluar lebih awal" di dalam fungsi.

match-case (Python 3.10 ke atas)

perintah = "maju"
match perintah:
    case "maju":
        print("Robot bergerak maju")
    case "kiri" | "kanan":
        print("Robot berbelok")
    case _:
        print("Perintah tidak dikenal")

Contoh lengkap: tahun kabisat

Aturan kabisat kalender Gregorian: habis dibagi 4, kecuali habis dibagi 100, tetapi tetap kabisat bila habis dibagi 400.

def kabisat(tahun):
    return tahun % 4 == 0 and (tahun % 100 != 0 or tahun % 400 == 0)

for t in [1900, 2000, 2024, 2026]:
    print(t, kabisat(t))
# 1900 False, 2000 True, 2024 True, 2026 False

Tanya jawab

Apa beda if, elif, dan else?
if memeriksa kondisi pertama, elif memeriksa kondisi tambahan bila sebelumnya salah, dan else dijalankan bila semua kondisi salah.
Kenapa harus pakai == bukan =?
Tanda = mengisi nilai ke variabel, sedangkan == membandingkan dua nilai.
Apakah Python punya switch-case?
Sejak Python 3.10 tersedia match-case yang fungsinya mirip, bahkan lebih kuat.
Bagaimana memeriksa beberapa nilai sekaligus?
Gunakan operator in, misalnya if hari in ("Sabtu", "Minggu").
