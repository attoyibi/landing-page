Render List di React: map, key, dan Filter yang Benar

Hampir semua aplikasi menampilkan daftar: produk, pesan, tugas, hasil pencarian. Di React, daftar dibuat dengan map, dan ada satu aturan yang sering dilanggar pemula: setiap item butuh key yang stabil dan unik. Melanggarnya menimbulkan bug halus yang sulit dilacak.

Menampilkan daftar dengan map

Mengapa key diperlukan

Saat data berubah, React membandingkan daftar lama dan baru untuk memutuskan elemen mana yang ditambah, dihapus, dipindah, atau dipertahankan. Key adalah identitas setiap item untuk perbandingan itu. Tanpa key yang stabil, React hanya bisa mencocokkan berdasarkan posisi.

Demonstrasi: apa yang terjadi bila key = indeks

Misalkan setiap baris memiliki kotak isian (state milik komponen baris). Bila item pertama dihapus dan key adalah indeks, React menganggap baris 0 masih baris 0, sehingga isian milik item yang dihapus tampak bergeser ke item lain. Kode di bawah mensimulasikan pencocokan itu.

Menyaring dan mengurutkan

sort mengubah array

Jangan memakai sort() langsung pada array props atau state: ia mengubah array aslinya. Salin dulu dengan [...data].sort(...) atau pakai toSorted() (JavaScript modern).

Daftar di state: tambah, hapus, ubah

AksiCara (tanpa mengubah array lama)Contoh

HapusfiltersetDaftar(daftar.filter(x => x.id !== id))

Sisip di posisislice dan sebarsetDaftar([...daftar.slice(0, i), baru, ...daftar.slice(i)])

Daftar komponen yang rapi

  • Letakkan key pada elemen terluar yang dikembalikan map (bukan pada elemen di dalam komponen anak).
  • Key tidak diteruskan sebagai props; bila anak butuh id, kirim sebagai props terpisah.
  • Gunakan <Fragment key=...> bila satu item menghasilkan beberapa elemen.
  • Untuk daftar panjang (ribuan), pertimbangkan virtualisasi (react-window, TanStack Virtual) agar hanya yang terlihat yang dirender.

Ringkasan
  • Tampilkan daftar dengan data.map(item => ).
  • Key harus stabil dan unik; hindari indeks dan Math.random().
  • filter dan toSorted (atau salinan lalu sort) tidak mengubah array asli.
  • Perbarui daftar di state dengan array baru: sebar, filter, map.

Tanya jawab

Mengapa React memperingatkan "Each child in a list should have a unique key"?
Karena item daftar tidak punya key; tambahkan key yang stabil pada elemen terluar yang dikembalikan map.
Bolehkah memakai key yang sama pada daftar berbeda?
Boleh; key hanya harus unik di antara saudara dalam daftar yang sama.
Bagaimana membuat id untuk data baru di sisi klien?
crypto.randomUUID() saat item dibuat (bukan saat render), atau id dari server setelah disimpan.
