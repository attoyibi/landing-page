React & Web Modern

Fitur Baru React 19: Actions, use, dan Form Lebih Ringkas

React 19 membawa perubahan terbesar pada cara menangani form dan operasi asinkron sejak hooks diperkenalkan. Banyak kode boilerplate untuk status "mengirim", galat, dan pembaruan optimistis berubah menjadi beberapa baris. Materi ini merangkum fitur utama, dengan fokus pada apa yang berubah dalam pekerjaan sehari-hari.

Oleh Muhammad Muchson Attoyibi·30 Oktober 2026·2 menit baca·Tingkat: Menengah

Sebaiknya sudah paham: React hooks, form React, async/await

Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • menjelaskan konsep Actions dan transisi asinkron
  • memakai useActionState untuk form dengan status pending dan galat
  • memakai useOptimistic untuk pembaruan instan
  • memahami hook use, ref sebagai props, dan metadata dokumen
  • mengenali perubahan yang dapat memengaruhi kode lama
Catatan ruang lingkup

Fitur di bawah ini tersedia di React 19 (proyek ini sendiri memakai React 19). Beberapa bagian yang bergantung pada server (Server Actions, Server Components) memerlukan framework yang mendukungnya, seperti Next.js; bagian lain berjalan di aplikasi klien biasa.

Actions: fungsi asinkron untuk perubahan data

Action adalah fungsi (sering asinkron) yang dijalankan di dalam transisi sehingga React mengelola status pending, galat, dan urutan pembaruan untuk Anda. Pada <form>, atribut action kini dapat menerima fungsi.

useActionState: status, galat, dan hasil

useFormStatus: tombol yang tahu form-nya sedang mengirim

useOptimistic: tampil instan, kembalikan bila gagal

Hook use: membaca Promise dan Context saat render
