BFS: Algoritma Mencari Jalur Terpendek (Simulasi Interaktif)

Bagaimana aplikasi peta, game, atau robot menemukan jalan keluar dari labirin? Salah satu cara paling dasar adalah BFS. Ia menjelajah seperti riak air: semua kotak sejauh 1 langkah dulu, lalu 2 langkah, dan seterusnya.

Lihat BFS bekerja

Perhatikan bahwa BFS menyebar merata ke segala arah, seperti riak. Karena itu, saat ia pertama kali mencapai tujuan, jalur yang ditemukan pasti yang terpendek (pada peta tanpa bobot).

Cara kerjanya

Kode Python

from collections import deque

def bfs(grid, mulai, tujuan):
    q = deque([mulai])
    asal = {mulai: None}
    while q:
        r, c = q.popleft()
        if (r, c) == tujuan:
            break
        for dr, dc in [(1,0),(-1,0),(0,1),(0,-1)]:
            nr, nc = r + dr, c + dc
            if (0 <= nr < len(grid) and 0 <= nc < len(grid[0])
                    and grid[nr][nc] == 0 and (nr, nc) not in asal):
                asal[(nr, nc)] = (r, c)
                q.append((nr, nc))
    # susun jalur dari tujuan kembali ke awal
    jalur, cur = [], tujuan if tujuan in asal else None
    while cur:
        jalur.append(cur)
        cur = asal[cur]
    return jalur[::-1]

BFS dan algoritma lain

Dalam praktik

Aplikasi peta modern memakai algoritma yang jauh lebih canggih dari BFS, tetapi prinsip menjelajah graf tetap menjadi dasarnya.

Tanya jawab

Apa bedanya BFS dan DFS?
BFS menjelajah per lapisan memakai queue, DFS menyelam sedalam mungkin memakai stack atau rekursi.
Apakah BFS bisa dipakai untuk peta jalan sungguhan?
Untuk jarak yang bobotnya berbeda, dipakai Dijkstra atau A*. BFS cocok bila setiap langkah berbiaya sama.
Apa yang dimaksud graf?
Kumpulan titik (node) yang dihubungkan garis (edge). Peta, jaringan pertemanan, dan jaringan komputer adalah contohnya.
