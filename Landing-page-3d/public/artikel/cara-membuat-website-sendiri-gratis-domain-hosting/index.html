Cara Membuat Website Sendiri Gratis: Domain dan Hosting

Website pribadi, portofolio, atau halaman usaha kecil bisa dibuat dengan biaya hampir nol. Banyak orang mengira harus membayar hosting mahal setiap bulan, padahal untuk website statis tersedia hosting gratis yang andal. Artikel ini menjelaskan bedanya domain dan hosting, lalu memandu langkah demi langkah.

Domain dan hosting: alamat dan rumah

Domain adalah alamat rumah, hosting adalah rumahnya. Saat seseorang mengetik alamat domain, sistem DNS menunjukkan ke server mana harus pergi, lalu server itu mengirim berkas website ke browser.

Langkah membuat website portofolio

  1. Siapkan berkas: index.html, style.css, dan gambar. Mulai sederhana: nama, foto, keahlian, proyek, kontak.
  2. Buat akun GitHub dan repositori baru, unggah berkas Anda.
  3. Aktifkan GitHub Pages di pengaturan repositori, pilih cabang utama sebagai sumber.
  4. Tunggu beberapa menit, lalu buka alamat namaanda.github.io/nama-repo.
  5. Perbarui dengan mengunggah ulang berkas; situs ikut berubah.

Domain sendiri: lebih profesional

Alamat seperti namaanda.github.io sudah cukup untuk mulai, tetapi domain sendiri terlihat lebih profesional. Domain .id dikelola PANDI (Pengelola Nama Domain Internet Indonesia) dan dijual lewat registrar resmi. Ada beberapa pilihan, misalnya .my.id untuk perorangan yang biasanya paling terjangkau, .biz.id untuk usaha, dan .id yang lebih umum. Syarat dan harga berbeda per jenis dan registrar.

  1. Beli domain di registrar resmi.
  2. Di pengaturan hosting (misalnya GitHub Pages atau Cloudflare), tambahkan domain kustom.
  3. Di pengelola DNS domain, buat catatan yang diminta hosting (biasanya CNAME atau A).
  4. Tunggu propagasi DNS, bisa beberapa menit sampai beberapa jam.
  5. Aktifkan HTTPS (biasanya otomatis di layanan modern).

Tanya jawab

Apa beda domain dan hosting?
Domain adalah alamat website, hosting adalah tempat berkas website disimpan dan disajikan.
Bisakah membuat website benar-benar gratis?
Bisa untuk website statis, memakai hosting gratis seperti GitHub Pages atau Cloudflare Pages dengan alamat subdomain bawaan.
Domain .my.id untuk siapa?
Domain .my.id ditujukan untuk perorangan dan biasanya termasuk yang paling terjangkau di antara domain .id.
Apakah perlu bisa coding untuk membuat website?
Untuk situs statis sederhana, HTML dan CSS dasar sudah cukup. Untuk toko online lengkap, biasanya dipakai platform atau pemrograman backend.
