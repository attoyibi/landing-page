Algoritma & Pemrograman Python

Python: Instalasi, REPL, Script, dan Virtual Environment

Hambatan pertama kebanyakan pemula bukan Python-nya, melainkan menyiapkan lingkungan kerja. Materi ini menjelaskan setiap bagian dengan jelas: apa itu interpreter, kapan memakai REPL dan kapan script, dan mengapa virtual environment penting sejak proyek pertama.

Oleh Muhammad Muchson Attoyibi·23 Oktober 2026·2 menit baca·Tingkat: Dasar
Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • memasang Python dan memeriksa versinya
  • membedakan REPL dan script serta kapan memakai masing-masing
  • membuat dan mengaktifkan virtual environment
  • memasang paket dengan pip dan mencatat dependensi

Memasang Python

  1. Unduh dari situs resmi python.org sesuai sistem operasi Anda, atau pakai pengelola paket (Homebrew di macOS, apt di Linux, winget di Windows).
  2. Di Windows, centang Add python.exe to PATH saat pemasangan agar perintah python dikenali.
  3. Buka terminal baru lalu periksa dengan perintah di bawah.
Pastikan versinya

Gunakan Python 3. Python 2 sudah tidak didukung sejak 1 Januari 2020. Bila ada petunjuk lama yang memakai print "teks" tanpa kurung atau raw_input, itu Python 2.

REPL: berbincang langsung dengan Python

REPL (Read-Eval-Print Loop) membaca satu perintah, menjalankannya, mencetak hasilnya, lalu menunggu perintah berikutnya. Ketik python di terminal untuk memulai. Prompt >>> berarti Python siap menerima perintah. Keluar dengan exit().

REPL ideal untuk mencoba potongan kecil, memeriksa perilaku fungsi, dan belajar. Tetapi isinya hilang saat Anda keluar. Untuk program yang utuh, gunakan script.

Script: menyimpan program dalam berkas

Tulis kode di berkas berakhiran .py, lalu jalankan dengan python namaberkas.py.

Virtual environment: satu proyek, satu lingkungan

Bayangkan proyek A membutuhkan versi 1 sebuah pustaka dan proyek B membutuhkan versi 2. Bila keduanya dipasang secara global, salah satu akan rusak. Virtual environment adalah folder terisolasi berisi salinan interpreter dan paket khusus untuk satu proyek.

Kebiasaan baik

Jangan meng-commit folder .venv ke Git. Cukup commit requirements.txt, dan tambahkan .venv/ ke .gitignore.

Latihan mandiri
1. Mengapa python -m pip install paket sering lebih aman daripada pip install paket?
Karena bentuk pertama memastikan pip yang dipakai adalah pip milik interpreter python yang sama. Bila ada banyak Python di komputer, pip saja bisa memasang paket ke interpreter yang berbeda.
2. Apa gunanya berkas requirements.txt?
Mencatat daftar paket beserta versinya agar lingkungan yang sama dapat dibuat ulang di komputer lain dengan pip install -r requirements.txt.
Coba kerjakan dulu sebelum membuka jawaban.
Ringkasan
  • REPL untuk mencoba cepat, script untuk program utuh.
  • Gunakan satu virtual environment per proyek agar paket tidak bentrok.
  • Catat dependensi dengan pip freeze dan pasang ulang dengan requirements.txt.
  • Jangan commit folder .venv ke Git.

Tanya jawab

Bagaimana memilih editor untuk Python?
Untuk pemula, VS Code dengan ekstensi Python atau PyCharm Community sudah sangat memadai. IDLE bawaan Python juga cukup untuk latihan awal.
Apakah conda sama dengan venv?
Keduanya mengelola lingkungan terisolasi. Conda juga mengelola paket non-Python dan banyak dipakai di data science. Untuk pemula, venv dan pip sudah cukup.
Mengapa perlu virtual environment bila hanya satu proyek?
Agar kebiasaannya terbentuk sejak awal, dan agar paket proyek tidak mengotori Python sistem yang mungkin dipakai alat lain.
