React & Web Modern

Belajar React dari Nol: Komponen, JSX, dan Props

React adalah pustaka JavaScript untuk membangun antarmuka dari potongan kecil yang disebut komponen. Satu ide inti menopang semuanya: tampilan adalah fungsi dari data. Berikan data, dapatkan tampilan. Dengan pegangan ini, sisa React terasa jauh lebih masuk akal.

Oleh Muhammad Muchson Attoyibi·30 Oktober 2026·3 menit baca·Tingkat: Pemula

Sebaiknya sudah paham: dasar HTML dan JavaScript (variabel, fungsi, array)

Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • menjelaskan apa itu komponen dan mengapa antarmuka dipecah menjadi komponen
  • menulis JSX dan memahami bahwa ia hanyalah JavaScript
  • mengirim data ke komponen lewat props
  • menyusun komponen kecil menjadi tampilan yang lebih besar (komposisi)
  • melihat HTML yang dihasilkan komponen dengan contoh yang dijalankan

Mengapa React ada

Membangun antarmuka dengan DOM langsung berarti Anda harus mengatur sendiri setiap perubahan: cari elemen, ubah teksnya, tambah atau hapus bagian. Semakin banyak keadaan (state) yang berubah, semakin mudah tampilan tidak sinkron dengan data. React membalik pendekatannya: Anda menyatakan seperti apa tampilan untuk data tertentu, dan React yang menyesuaikan DOM saat data berubah.

Komponen: fungsi yang mengembalikan tampilan

Komponen React adalah fungsi JavaScript biasa yang namanya diawali huruf besar dan mengembalikan tampilan (JSX). Kita jalankan langsung dengan React 19 dan renderToString, yang menghasilkan HTML dari komponen.

JSX: bukan HTML, tapi JavaScript

JSX terlihat seperti HTML, tetapi aturannya sedikit berbeda karena sebenarnya ia ekspresi JavaScript. Yang perlu dihafal hanya beberapa hal.

class="kotak"className="kotak"class adalah kata kunci JavaScript

style="color: red"style={{ color: "red" }}objek JavaScript; kurung kurawal luar untuk ekspresi

Props: data masuk ke komponen

Props (properties) adalah argumen komponen. Komponen menerimanya dalam satu objek dan hanya membacanya: props tidak boleh diubah di dalam komponen penerima.

Satu arah

Aturan emas: props mengalir ke bawah, dari induk ke anak (aliran data satu arah). Anak tidak mengubah props; bila ia perlu memberi tahu induk, induk mengirim fungsi lewat props (callback). Aturan sederhana ini membuat aliran data mudah dilacak.

Komposisi: komponen di dalam komponen

Cara memecah antarmuka menjadi komponen

  1. Gambar atau lihat desainnya, lalu lingkari setiap bagian yang berdiri sendiri.
  2. Beri nama sesuai fungsinya (KartuProduk, DaftarPesanan), bukan sesuai tampilan (KotakBiru).
  3. Pecah lagi bila suatu bagian dipakai berulang atau terlalu panjang untuk dibaca sekilas.
  4. Tentukan data apa yang dibutuhkan tiap komponen: itulah props-nya.
  5. Satu komponen sebaiknya melakukan satu hal (prinsip tanggung jawab tunggal).

Ringkasan
  • Komponen adalah fungsi (huruf besar) yang mengembalikan JSX.
  • JSX adalah sintaks JavaScript: {} untuk ekspresi, className, onClick, style objek.
  • Props mengalir dari induk ke anak dan hanya dibaca; children memungkinkan komposisi.
  • Pecah antarmuka menjadi komponen kecil berdasarkan fungsi dan penggunaan ulang.

Tanya jawab

Apa bedanya React dan framework seperti Next.js?
React adalah pustaka untuk membangun antarmuka. Next.js adalah framework di atasnya yang menambah routing, rendering di server, dan optimasi.
Apakah harus belajar JavaScript dulu?
Ya, dasarnya: variabel, fungsi, array dan objek, map/filter, dan destructuring. React hanyalah JavaScript dengan konvensi tertentu.
Apakah React masih relevan?
Ya. React termasuk pustaka antarmuka paling banyak dipakai dan menjadi dasar ekosistem seperti Next.js dan React Native.
