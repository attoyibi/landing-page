Binary Search Dijelaskan Visual: Mencari dengan Membagi Dua

Menebak angka 1 sampai 100 dengan petunjuk "lebih besar" atau "lebih kecil"? Strategi terbaik adalah selalu menebak di tengah. Itulah binary search: setiap langkah membuang separuh kemungkinan, sehingga data sebesar apa pun tetap cepat dicari.

Oleh Muhammad Muchson Attoyibi·23 Oktober 2026·1 menit baca

Idenya: buang separuh setiap langkah

Berapa cepat?

Linear search memeriksa satu per satu: pada data sebanyak n, kasus terburuk n langkah. Binary search memeriksa sekitar log₂(n) langkah. Untuk satu juta data, itu sekitar 20 langkah, bukan satu juta. Karena itu binary search disebut O(log n).

Kode Python

def binary_search(data, target):
    lo, hi = 0, len(data) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if data[mid] == target:
            return mid
        if data[mid] < target:
            lo = mid + 1      # buang separuh kiri
        else:
            hi = mid - 1      # buang separuh kanan
    return -1                 # tidak ditemukan

print(binary_search([3, 8, 15, 21, 40, 57], 21))   # 3
Syarat penting

Binary search hanya bekerja bila data sudah terurut. Mengurutkan dulu juga butuh waktu, jadi untuk satu kali pencarian pada data acak, pencarian linear bisa lebih sederhana.

Di mana binary search dipakai?

  • Mencari kata di kamus atau data terurut pada database (indeks).
  • Menebak parameter, misalnya mencari versi pertama yang memunculkan bug (git bisect).
  • Fungsi bawaan bahasa pemrograman untuk data terurut (misalnya modul bisect di Python).

Tanya jawab

Apa bedanya binary search dan linear search?
Linear memeriksa satu per satu, biner membagi dua rentang setiap langkah. Biner jauh lebih cepat pada data besar yang terurut.
Apakah binary search bisa untuk teks?
Bisa, selama data terurut berdasarkan aturan yang sama dengan perbandingan yang dipakai.
Mengapa mid dihitung dengan (lo + hi) // 2?
Itu nilai tengah rentang. Pada bahasa dengan bilangan bulat terbatas, rumus lo + (hi - lo) // 2 menghindari overflow.
