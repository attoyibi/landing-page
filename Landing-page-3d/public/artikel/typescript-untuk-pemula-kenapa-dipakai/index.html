TypeScript untuk Pemula: Kenapa Banyak Tim Memakainya

JavaScript membiarkan Anda mengirim angka ke fungsi yang mengharapkan teks, lalu baru error saat aplikasi dipakai pengguna. TypeScript menambahkan tipe ke JavaScript sehingga banyak kesalahan seperti itu tertangkap di editor, sebelum kode dijalankan.

Oleh Muhammad Muchson Attoyibi·28 Oktober 2026·1 menit baca

Bug yang dicegah TypeScript

// JavaScript: lolos, tapi hasilnya salah
function totalHarga(harga, jumlah) { return harga * jumlah; }
totalHarga('45000', 2);        // 90000? hampir kebetulan
totalHarga({ harga: 45000 }, 2); // NaN, ketahuan belakangan

// TypeScript: ditandai merah di editor
function totalHarga(harga: number, jumlah: number): number {
  return harga * jumlah;
}
totalHarga('45000', 2);
// Error: Argument of type 'string' is not assignable to parameter of type 'number'.

Kode TypeScript dikompilasi menjadi JavaScript biasa. Tipe hanya ada saat pengembangan; di browser dan Node.js yang berjalan tetap JavaScript.

Tipe dasar

let nama: string = 'Ani';
let umur: number = 21;
let aktif: boolean = true;
let nilai: number[] = [80, 92];
let kosong: string | null = null;    // union: string ATAU null

// TypeScript sering bisa menebak sendiri (inference)
let kota = 'Malang';   // otomatis string

Interface dan type untuk bentuk objek

interface Produk {
  id: number;
  nama: string;
  harga: number;
  diskon?: number;        // opsional
  readonly sku: string;   // tidak boleh diubah
}

function tampilkan(p: Produk) {
  return `${p.nama}: Rp${p.harga - (p.diskon ?? 0)}`;
}

tampilkan({ id: 1, nama: 'Frame', harga: 450000, sku: 'FR-01' });   // ok
tampilkan({ id: 1, nama: 'Frame', sku: 'FR-01' });
// Error: Property 'harga' is missing

Union dan literal: membatasi pilihan

type StatusPesanan = 'baru' | 'dibayar' | 'dikirim' | 'selesai';

function label(s: StatusPesanan) {
  switch (s) {
    case 'baru': return 'Menunggu pembayaran';
    case 'dibayar': return 'Sedang dikemas';
    case 'dikirim': return 'Dalam perjalanan';
    case 'selesai': return 'Selesai';
  }
}
label('dibatalkan'); // Error: tidak termasuk pilihan

Typo seperti 'dikrim' langsung ketahuan, dan editor memberi saran otomatis untuk setiap pilihan.

Generics: tipe yang bisa diisi

interface ResponsApi<T> {
  data: T;
  error: string | null;
}

async function ambil<T>(url: string): Promise<ResponsApi<T>> {
  const res = await fetch(url);
  return res.json();
}

const hasil = await ambil<Produk[]>('/api/produk');
hasil.data[0].nama;   // editor tahu ini string

Manfaat yang paling terasa

Cara mulai di proyek JavaScript lama

  1. Pasang: npm install -D typescript, lalu npx tsc --init.
  2. Aktifkan allowJs agar file .js dan .ts bisa hidup bersama.
  3. Ubah file satu per satu, mulai dari utilitas kecil.
  4. Setelah sebagian besar file .ts, aktifkan strict: true.
  5. Hindari any; bila terpaksa, pakai unknown lalu periksa tipenya.
Jebakan any

Memberi tipe any di mana-mana mematikan manfaat TypeScript. Anggap any sebagai utang yang harus dibayar.

Tanya jawab

Apakah TypeScript memperlambat aplikasi?
Tidak saat berjalan, karena yang dijalankan tetap JavaScript. Yang bertambah hanya sedikit waktu kompilasi saat pengembangan.
Interface atau type?
Keduanya mirip untuk bentuk objek. Banyak tim memakai interface untuk objek dan type untuk union atau kombinasi. Yang penting konsisten.
Apakah Node.js bisa menjalankan TypeScript langsung?
Versi Node.js terbaru mendukung menjalankan file .ts dengan menghapus tipe (type stripping). Untuk proyek besar, tetap jalankan tsc untuk pemeriksaan tipe.
