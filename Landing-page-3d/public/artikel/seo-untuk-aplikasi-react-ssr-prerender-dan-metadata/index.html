React & Web Modern

SEO untuk Aplikasi React: SSR, Prerender, dan Metadata

Anda membangun aplikasi React yang bagus, tetapi tidak muncul di Google. Penyebabnya sering sama: HTML yang dikirim server hanya berisi div kosong, dan isi halaman baru ada setelah JavaScript dijalankan. Mesin pencari modern dapat menjalankan JavaScript, tetapi lebih lambat dan tidak selalu andal. Cara terbaik adalah memastikan HTML sudah berisi konten sejak awal.

Oleh Muhammad Muchson Attoyibi·30 Oktober 2026·3 menit baca·Tingkat: Menengah

Sebaiknya sudah paham: React dasar, React Router, dasar HTML

Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • menjelaskan perbedaan CSR, SSR, SSG, dan prerender
  • mengenali masalah SEO pada SPA murni
  • mengatur judul, deskripsi, canonical, dan Open Graph per halaman
  • membuat sitemap dan data terstruktur
  • memahami hubungan SEO dengan Core Web Vitals dan aksesibilitas

Apa yang dilihat mesin pencari

Penjelajah mengunduh HTML terlebih dahulu. Bila konten sudah ada di sana, ia langsung bisa memahaminya. Bila HTML hanya berisi <div id="root"></div>, ia harus menjalankan JavaScript dan menunggu render, antrean tambahan yang menunda indeks dan rawan gagal. Peramban sosial (pratinjau tautan WhatsApp, Facebook, X) bahkan umumnya tidak menjalankan JavaScript.

Empat strategi rendering

StrategiHTML dibuatCocok untukSEO
CSR (SPA murni)Di browserDasbor di balik login, aplikasi internalLemah untuk halaman publik
SSRDi server pada setiap permintaanHalaman dinamis dan personal yang perlu SEOBaik; butuh server
SSGSaat build, sekaliBlog, dokumentasi, landing page, katalog yang jarang berubahSangat baik dan cepat
ISR / revalidateSaat build lalu diperbarui berkalaKatalog besar yang sesekali berubahSangat baik
Pilih sesuai halaman

Aplikasi di balik login tidak perlu SEO, jadi CSR sudah cukup. Untuk halaman publik (landing page, artikel, produk), pilih SSG atau SSR. Framework seperti Next.js, Remix/React Router framework mode, atau Astro menyediakannya; atau lakukan prerender pada proyek Vite untuk halaman tertentu.
