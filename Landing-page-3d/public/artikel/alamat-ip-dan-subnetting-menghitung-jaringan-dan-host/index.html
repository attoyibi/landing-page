Alamat IP dan Subnetting: Menghitung Jaringan dan Host

Alamat IP seperti nomor rumah dengan nama jalan: sebagian untuk jaringan, sebagian untuk perangkat di dalamnya. Subnetting adalah seni membagi "jalan" itu menjadi blok yang pas. Setelah memahami biner, subnetting hanyalah menggeser garis pemisah antara bit jaringan dan bit host.

Sebaiknya sudah paham: sistem bilangan biner, model OSI dan TCP/IP

Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • menjelaskan struktur alamat IPv4 dan notasi CIDR
  • menghitung alamat jaringan, broadcast, rentang host, dan jumlah host dari alamat dan prefiks
  • membagi blok jaringan menjadi subnet dengan kebutuhan tertentu
  • mengenali rentang alamat privat dan alamat khusus
  • menjelaskan perbedaan dasar IPv4 dan IPv6

Struktur alamat IPv4

Alamat IPv4 terdiri dari 32 bit, ditulis sebagai empat oktet desimal. Notasi CIDR /n menyatakan bahwa n bit pertama adalah bagian jaringan, sisanya bagian host.

Menghitung manual

  1. Ubah prefiks menjadi mask: /26 = 26 bit satu = 255.255.255.192.
  2. Alamat jaringan = alamat AND mask: 192.168.1.130 AND 255.255.255.192 = 192.168.1.128.
  3. Broadcast = alamat jaringan dengan seluruh bit host bernilai 1: 192.168.1.191.
  4. Host valid: dari jaringan + 1 sampai broadcast − 1: 192.168.1.129 – 192.168.1.190.
  5. Jumlah host = 2^(32 − prefiks) − 2 = 64 − 2 = 62 (dua alamat dipakai jaringan dan broadcast).

Membagi jaringan (subnetting)

Kasus: blok 192.168.10.0/24 harus dibagi untuk empat departemen dengan kebutuhan host: Teknik 100, Keuangan 50, SDM 25, Tamu 10. Aturan: alokasikan dari kebutuhan terbesar, pilih prefiks terkecil yang cukup (VLSM, Variable Length Subnet Mask).

Konteks

Kehabisan alamat IPv4 mendorong NAT dan, jangka panjang, IPv6. Dua-duanya hidup berdampingan (dual-stack) selama bertahun-tahun. Subnet IPv6 umumnya /64 untuk satu jaringan lokal, jadi "menghemat alamat" tidak lagi menjadi tujuan subnetting.

Latihan mandiri
1. Berapa alamat jaringan dan broadcast untuk 10.4.77.200/20?
/20: blok 16 dalam oktet ketiga (256 − 240). 77 berada di blok 64–79; jaringan 10.4.64.0, broadcast 10.4.79.255.
2. Perlu jaringan untuk 500 host. Prefiks apa yang paling kecil yang cukup?
/23 (510 host); /24 hanya 254.
3. Apakah 192.168.5.255/24 alamat host valid?
Bukan; itu alamat broadcast untuk jaringan 192.168.5.0/24.
4. Mengapa 192.168.1.130 dan 192.168.1.60 berada di subnet berbeda pada /26?
Blok /26 berukuran 64: 192.168.1.0–63 dan 192.168.1.128–191 adalah subnet berbeda.
Coba kerjakan dulu sebelum membuka jawaban.
Ringkasan
  • IPv4: 32 bit; CIDR /n berarti n bit jaringan.
  • Jaringan = alamat AND mask; broadcast = bit host semua 1; host = 2^(32−n) − 2.
  • VLSM: alokasikan kebutuhan terbesar lebih dulu dengan prefiks yang cukup.
  • Rentang privat, loopback, link-local, dan multicast memiliki fungsi khusus.
  • IPv6 memakai 128 bit dan menghilangkan kelangkaan alamat.

Tanya jawab

Apa itu DHCP?
Protokol yang memberi perangkat alamat IP, mask, gateway, dan DNS secara otomatis.
Apa itu default gateway?
Alamat router tempat perangkat mengirim lalu lintas yang tujuannya di luar jaringan lokal.
Apa itu kelas A, B, C?
Sistem lama berdasarkan oktet pertama (A: /8, B: /16, C: /24). Digantikan oleh CIDR yang fleksibel sejak 1990-an.
