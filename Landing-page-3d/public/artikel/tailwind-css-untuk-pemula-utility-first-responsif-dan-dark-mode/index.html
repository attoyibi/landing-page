Tailwind CSS untuk Pemula: Utility-First, Responsif, Dark Mode

Tailwind CSS mengubah cara menulis gaya: alih-alih menamai kelas dan menulis aturan CSS di berkas terpisah, Anda menyusun kelas utilitas kecil langsung di markup. Awalnya terasa aneh, bahkan "kotor". Setelah beberapa hari banyak orang menyadari kecepatannya: tidak ada lagi bingung menamai, berpindah berkas, atau takut menghapus CSS yang mungkin masih dipakai.

Oleh Muhammad Muchson Attoyibi·30 Oktober 2026·2 menit baca·Tingkat: Pemula

Sebaiknya sudah paham: dasar HTML dan CSS

Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • menjelaskan pendekatan utility-first dan kelebihan serta kekurangannya
  • memakai kelas spacing, tipografi, warna, flex, dan grid
  • membuat tampilan responsif dengan breakpoint mobile-first
  • memakai varian state (hover, focus) dan dark mode
  • membuat komponen yang dapat dipakai ulang tanpa menggandakan kelas

State, fokus, dan dark mode

Menghindari pengulangan kelas

  • Jadikan komponen: di React, bungkus markup berulang dalam komponen (Tombol, Kartu) sehingga kelas ditulis sekali.
  • Varian lewat props: petakan nama varian ke string kelas (atau pakai pustaka kecil seperti clsx dan tailwind-merge).
  • @apply bisa dipakai untuk pola yang sangat umum di CSS, tetapi jangan berlebihan: ia mengembalikan Anda ke penamaan kelas yang ingin dihindari.
  • Tema (warna merek, font) dikonfigurasi di satu tempat sehingga seluruh situs mengikuti.

Kelebihan dan kekurangan

KelebihanKekurangan

Tetap pelajari CSS

Tailwind tidak menggantikan pemahaman CSS: flexbox, grid, specificity, dan model kotak tetap dasarnya. Orang yang paham CSS justru paling produktif dengan Tailwind karena tahu apa yang terjadi di balik kelasnya.

Latihan mandiri
1. Tulis kelas untuk tombol biru dengan sudut membulat, padding vertikal 8px dan horizontal 16px.
bg-blue-600 text-white rounded-lg py-2 px-4 (py-2 = 0,5rem = 8px; px-4 = 1rem = 16px)
2. Buat grid 2 kolom di tablet dan 4 kolom di desktop.
grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4
3. Mengapa menghapus outline fokus tanpa pengganti buruk?
Pengguna keyboard kehilangan petunjuk elemen yang sedang fokus; gunakan focus-visible dengan ring atau outline yang jelas.
4. Kapan CSS biasa atau CSS Modules lebih cocok dari Tailwind?
Untuk animasi kompleks, gaya yang sangat dinamis dari data, atau tim yang sudah punya sistem desain berbasis CSS yang matang.
Coba kerjakan dulu sebelum membuka jawaban.
Ringkasan
  • Utility-first: kelas kecil bermakna tunggal disusun langsung di elemen.
  • Skala bawaan (spacing, warna, ukuran) menjaga konsistensi.
  • Responsif mobile-first dengan sm:, md:, lg:; varian state seperti hover: dan focus-visible:, plus dark:.
  • Hindari pengulangan dengan komponen dan peta varian; tetap kuasai dasar CSS.

Tanya jawab

Apakah Tailwind membuat CSS membengkak?
Tidak; hanya kelas yang benar-benar dipakai yang dibangkitkan sehingga CSS produksi biasanya kecil.
Bagaimana memasang Tailwind di Vite?
Pasang paket tailwindcss dan plugin Vite-nya, impor Tailwind di berkas CSS utama, lalu mulai memakai kelas; ikuti panduan resmi untuk versi terbaru.
Apakah Tailwind cocok untuk proyek besar?
Ya, banyak produk besar memakainya; kuncinya komponen yang dapat dipakai ulang dan tema terpusat.
