PBO dengan Java

Tipe Data, Variabel, dan Operator di Java

Java bertipe statis: setiap variabel punya tipe yang ditetapkan saat dideklarasikan, dan kompiler menolak penggunaan yang tidak cocok. Aturan ketat ini menghindarkan banyak kesalahan, tetapi memunculkan jebakan seperti overflow dan pembagian bilangan bulat yang perlu dipahami.

Sebaiknya sudah paham: program Java pertama

Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • menyebutkan delapan tipe primitif beserta rentangnya
  • mendeklarasikan variabel, konstanta (final), dan memakai var
  • melakukan casting melebar dan menyempit
  • menjelaskan integer overflow, pembagian bilangan bulat, dan presisi double
  • membedakan tipe primitif dan tipe referensi

Aturan praktis

Untuk uang, jangan pakai float atau double. Gunakan BigDecimal (dibuat dari String) atau simpan dalam satuan terkecil sebagai long (misalnya rupiah penuh atau sen).

Primitif vs referensi

Latihan mandiri
1. Berapa hasil (int) 7.9 dan (int) -7.9?
7 dan −7; casting memotong ke arah nol.
2. Mengapa 0.1 + 0.2 tidak sama dengan 0.3?
Bilangan 0.1 dan 0.2 tidak dapat dinyatakan persis dalam biner, sehingga hasil jumlahnya sedikit melenceng.
3. Tulis ekspresi untuk menghitung rata-rata tiga int a, b, c sebagai double.
(a + b + c) / 3.0
4. Mengapa Integer.MAX_VALUE + 1 menghasilkan bilangan negatif?
Bit tanda terbalik akibat limpahan pada representasi komplemen dua; nilai berputar ke batas bawah.
Coba kerjakan dulu sebelum membuka jawaban.
Ringkasan
  • Delapan primitif: byte, short, int, long, float, double, char, boolean.
  • Casting menyempit dapat membuang data tanpa peringatan.
  • Waspadai pembagian int, overflow, dan presisi double; uang pakai BigDecimal.
  • == membandingkan nilai pada primitif tetapi alamat pada objek.

Tanya jawab

Kapan memakai var?
Saat tipe jelas dari sisi kanan, misalnya var daftar = new ArrayList(). Hindari bila membuat pembaca bingung tentang tipe sebenarnya.
Apa bedanya int dan Integer?
int adalah primitif; Integer adalah kelas pembungkus (wrapper) yang dapat bernilai null dan dipakai di koleksi seperti List.
Apakah char dan String sama?
Tidak. char satu karakter dengan tanda kutip tunggal; String adalah objek berisi rangkaian karakter dengan tanda kutip ganda.
