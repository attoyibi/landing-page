Laravel & Backend

Belajar Laravel dari Nol: MVC, Routing, Controller, Blade

Laravel adalah kerangka kerja PHP yang paling populer untuk membangun aplikasi web. Daya tariknya sederhana: ia menyediakan jawaban yang rapi untuk hal-hal yang selalu Anda butuhkan (routing, basis data, autentikasi, validasi, antrean) sehingga Anda dapat fokus pada logika bisnis. Materi ini membangun gambaran besar: bagaimana satu permintaan bergerak melalui aplikasi Laravel.

Tujuan belajar

Setelah membaca dan mencoba materi ini, Anda mampu:

  • memasang Laravel dan memahami struktur folder utama

  • membuat view dengan Blade (escaping, kondisi, perulangan, layout)
  • menelusuri alur satu permintaan dari browser sampai respons

Memasang Laravel

Keamanan dasar

Server web harus diarahkan ke folder public/, bukan ke akar proyek. Bila akar proyek terbuka ke publik, berkas .env (berisi kata sandi basis data dan kunci) bisa diunduh siapa pun. Ini salah satu kesalahan deploy yang paling berbahaya.

View dengan Blade

Ringkasan alur satu permintaan

  1. Server web mengirim semua permintaan ke public/index.php.
  2. Laravel memulai aplikasi, memuat konfigurasi, dan menjalankan middleware global (sesi, CSRF, dan lainnya).
  3. Router mencocokkan URL dan metode ke rute, lalu memanggil controller.
  4. Controller memakai model untuk membaca atau menulis basis data, lalu mengembalikan view atau respons JSON.
  5. Respons kembali melewati middleware dan dikirim ke browser.
Latihan mandiri
1. Tulis rute GET /kategori/{slug} ke method show pada KategoriController.
Route::get("/kategori/{slug}", [KategoriController::class, "show"]);
2. Mengapa controller sebaiknya tipis?
Agar mudah dibaca dan diuji; logika bisnis dipindah ke model atau kelas layanan yang dapat dipakai ulang.
3. Apa gunanya route model binding?
Parameter {produk} otomatis diubah menjadi objek Produk dari basis data dan memberi 404 bila tidak ada.
4. Mengapa .env tidak boleh dikomit ke Git?
Berisi kata sandi dan kunci rahasia; gunakan .env.example sebagai templat tanpa rahasia.
Coba kerjakan dulu sebelum membuka jawaban.
Ringkasan
  • MVC: model (data), view (tampilan), controller (alur).
  • Semua permintaan masuk lewat public/index.php; router memilih controller.
  • Blade memberi templat dengan escaping otomatis, layout, kondisi, dan perulangan.
  • Artisan mempercepat pekerjaan; arahkan server web ke public/ dan jaga .env tetap rahasia.

Tanya jawab

Mengapa memilih Laravel?
Ekosistem besar, dokumentasi sangat baik, banyak bawaan (autentikasi, antrean, tes), dan komunitas aktif, termasuk di Indonesia.
Apakah masih perlu PHP murni?
Memahami PHP dasar penting; Laravel hanya mengatur cara memakainya dengan rapi.
Apa itu starter kit?
Kerangka awal dengan autentikasi dan tampilan siap pakai (misalnya Breeze, atau starter kit React/Vue/Livewire pada installer baru).
