How the Internet Works: What Happens When You Open a Site

You type an address, press Enter and the page appears in a flash. Behind it is a series of steps involving several systems in different places around the world. Understanding it helps you make sense of many things, from slow sites to 404 errors.

By Muhammad Muchson Attoyibi·October 23, 2026·1 min read

Key takeaways

  • The journey: type the address, DNS finds the IP address, a secure connection is made, the browser sends an HTTP request, the server answers and the browser renders the page.
  • DNS is the internet's phone book; HTTPS is HTTP with encryption, shown by the padlock in the address bar.
  • Know the status codes: 200 success, 301/302 redirect, 403 forbidden, 404 not found, 500 server error, 503 unavailable.
  • Slow sites usually come from large images, heavy JavaScript, a distant server with no CDN, no caching or many external requests.

Try it yourself

The browser's developer tools (press F12, the Network tab) show every request made while the page opens, with its size and time. It is the best way to see all the steps above for yourself.

FAQ

What is the difference between HTTP and HTTPS?
HTTPS is HTTP with encryption (TLS) so data is not easily eavesdropped on the way. Almost every site uses it now.
What is a CDN?
A network of servers in many locations that hold copies of content so it is delivered from the point nearest the visitor.
Why can a site open on one network but not another?
It can be a DNS problem, blocking, or the route taken by the internet service provider.
