Selection Sort and Insertion Sort: Two Simple Methods

After bubble sort, the next two simple algorithms usually taught are selection sort and insertion sort. Both are O(n²) in the general case, but they think differently, and one of them is very useful in the real world.

By Muhammad Muchson Attoyibi·October 23, 2026·1 min read

Key takeaways

  • Selection sort picks the smallest of the remaining data and swaps it into place: few swaps, but it always scans everything left.
  • Insertion sort inserts each item into its place among those already sorted, like arranging cards in your hand.
  • On almost-sorted data insertion sort is very fast, while selection sort stays slow.
  • Advanced algorithms such as Timsort use insertion sort for small pieces, because it is very efficient at small sizes.

Selection sort: pick the smallest

Find the smallest value in all the data and swap it with the first element. Then find the smallest in the rest and swap it with the second element. Repeat until done. The number of swaps is small, but it always examines all the remaining data, so it gains nothing from data that is already almost sorted.

Insertion sort: insert it in its place

Like arranging cards in your hand: take one card and insert it in the right place among the cards already sorted. If the data is almost sorted, hardly any shifting is needed, so it is very fast.

An interesting fact

Advanced sorting algorithms such as Timsort (used by sorted() in Python) use insertion sort for small pieces, because at small sizes it is very efficient.

FAQ

Which should I learn first?
Bubble sort, then selection, then insertion. After that the more efficient merge sort and quick sort.
Is insertion sort used in the real world?
Yes, especially for small data and as part of hybrid algorithms.
What does it mean for an algorithm to be stable?
Elements with equal values stay in their original order after sorting.
