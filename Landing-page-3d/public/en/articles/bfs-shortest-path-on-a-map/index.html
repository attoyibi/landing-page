BFS: The Shortest-Path Algorithm (Interactive Demo)

How does a map app, a game or a robot find its way out of a maze? One of the most basic ways is BFS. It explores like ripples in water: every square 1 step away first, then 2 steps, and so on.

By Muhammad Muchson Attoyibi·October 23, 2026·1 min read

Key takeaways

  • BFS puts the start in a queue, takes the front square, adds its unvisited neighbours and repeats until it reaches the goal.
  • Because it spreads evenly like a ripple, the first time it reaches the goal the path is the shortest (on a map without weights).
  • The queue is the key: what goes in first is explored first.
  • For maps with different step costs, use Dijkstra or A*; DFS dives deep using a stack or recursion.

FAQ

What is the difference between BFS and DFS?
BFS explores layer by layer using a queue, DFS dives as deep as it can using a stack or recursion.
Can BFS be used for a real road map?
For distances with different weights, Dijkstra or A* is used. BFS fits when every step costs the same.
What is a graph?
A set of points (nodes) joined by lines (edges). Maps, friendship networks and computer networks are examples.
