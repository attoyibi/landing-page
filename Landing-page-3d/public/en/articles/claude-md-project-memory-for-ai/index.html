CLAUDE.md: Project Memory So AI Knows Your Rules

Imagine having to explain your project again to a new colleague every day. That is what happens when a coding agent has no fixed notes. A simple file called CLAUDE.md in the project folder solves it, and makes results much more consistent.

By Muhammad Muchson Attoyibi·October 23, 2026·1 min read

Key takeaways

  • CLAUDE.md is a text file (usually Markdown) the agent reads at the start of each session, so you do not repeat the same instructions.
  • Useful contents: how to run and test, the folder structure, code style, hard rules and important notes.
  • Keep it short and specific to the project; write what the agent cannot guess, not general policy.
  • Update it whenever the agent repeats a mistake, and never put secrets in it, because it is stored in the repository.

What is CLAUDE.md?

CLAUDE.md is a text file (usually Markdown) in your project that the agent reads when it starts a session. Its contents are guidance: how to run the project, the folder structure, code style and special rules. Because it is read every session, you do not need to repeat the same instructions.

Contents that work

FAQ

Is CLAUDE.md mandatory?
Not mandatory, but it helps consistency a lot, especially on long-running projects or ones with several people.
Is this file only for Claude Code?
The name is specific to that tool, but the principle applies to other coding agents that read a project guidance file.
What if the agent ignores its contents?
Check that the instructions are clear and do not contradict each other. Rules that are truly mandatory are better backed by tests or an automatic mechanism.
